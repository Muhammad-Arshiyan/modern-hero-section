# 🚀 Modern Hero Section

A modern, responsive Hero Section built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates clean code structure, responsive design, and JavaScript DOM manipulation using `classList.toggle()`.

## ✨ Features

* 📱 Fully Responsive Design
* 🌙 Dark / Light Mode Toggle
* 🍔 Mobile Navigation Menu
* ⚡ JavaScript `classList.toggle()`
* 🎨 Modern UI Design
* 🧹 Clean & Organized Code
* 📂 Separate HTML, CSS & JavaScript Files
* ♿ Semantic HTML Structure
* 🔥 Font Awesome Icons

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome

## 📁 Project Structure

modern-hero-section/
├── index.html

└── script.js

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/your-username/modern-hero-section.git
```

2. Open the project folder.

```bash
cd modern-hero-section
```

3. Open `index.html` in your browser or run it with **Live Server**.
