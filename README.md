# 🚀 Modern Hero Section

A modern, responsive Hero Section built with **HTML5**, **CSS3**, and **JavaScript**. This project demonstrates responsive web design, semantic HTML5, dark/light mode implementation, and clean DOM manipulation using JavaScript `classList` methods.

---

## ✨ Features

- 📱 Fully Responsive Layout
- 🌙 Dark / Light Mode Toggle
- 🍔 Responsive Mobile Navigation
- 🎨 Modern & Clean User Interface
- ⚡ JavaScript DOM Manipulation
- 🔄 Theme Switching with `classList.toggle()`
- 🎯 Dynamic Icon Switching
- ♿ Semantic HTML5 Structure
- 🧹 Clean & Organized Code
- 📂 Separate HTML, CSS & JavaScript Files
- 🔥 Font Awesome Icons

---

## 🛠️ Built With

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/modern-hero-section.git
```

### 2. Navigate to the Project Folder

```bash
cd modern-hero-section
```

### 3. Run the Project

Open **index.html** in your preferred browser or launch the project using **Live Server** in Visual Studio Code.
